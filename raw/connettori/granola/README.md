# Granola — export note e trascrizioni

Export delle call registrate con Granola dal team Musa AI (account condiviso del team), periodo Nov 2025 – Lug 2026.
Un file per meeting, nome `AAAA-MM-GG_<slug>.md`. Ogni file contiene intestazione (data, durata, partecipanti),
le note generate automaticamente da Granola e la trascrizione completa con timestamp.
Comprende sia call con i clienti sia riunioni interne. Le trascrizioni sono automatiche e non riviste: possono contenere
imprecisioni minori di riconoscimento vocale.
