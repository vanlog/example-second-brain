# Fatture in Cloud — export

Export dell'account Fatture in Cloud di Musa AI: `fatture/` contiene le fatture emesse (una per file, con stato di incasso), `clienti/` l'anagrafica fiscale dei clienti fatturati.

Numerazione fattura: `<anno>-<id-offerta><lettera>`, dove `<anno>-<id-offerta>` è il numero dell'offerta/preventivo di riferimento e la lettera è progressiva per ogni fattura emessa a fronte di quell'offerta (A, B, C, ...).
